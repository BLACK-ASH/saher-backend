# Plan 04-02: Session Attendance Report Export (PDF/Excel via BullMQ)

## Objective

Add export endpoints for session attendance reports in PDF and Excel, mirroring the existing attendance export pipeline: controller → BullMQ queue → worker → notification with download action.

## must_haves

- [ ] `GET /api/events/export/report` accepts `format=pdf|xlsx` and `sessionId` query param, enqueues a BullMQ job, and returns a processing response.
- [ ] Worker generates PDF via Puppeteer and Excel via ExcelJS, saves to `public/temp/`, sends notification with download URL.
- [ ] `GET /api/events/download/:fileName` serves the generated file (or reuses attendance download route).
- [ ] Redis cache key prevents duplicate job submissions for the same session+format+user+date combo.
- [ ] `pnpm typecheck` exits 0.
- [ ] `pnpm lint` exits 0.

## Task 1: Create session export controller + queue

### read_first

- `src/attendance/export/report.ts` — the attendance export controller to mirror
- `src/attendance/export/excel.service.ts` — ExcelJS pattern
- `src/events/session/session-attendance.controller.ts` — current session attendance data access
- `src/database/session.model.ts` — Session schema (participants, attendance refs)
- `src/libs/redis/redis-utils.ts` — createKey, getCache, setCache, deleteCache
- `src/libs/redis/redis-client.ts` — bullmqConnection
- `src/libs/class/date-range.ts` — DateRange utilities
- `src/libs/utils/browser.ts` — getBrowser for Puppeteer
- `src/events/events.routes.ts` — where to mount the new route

### action

1. Create `src/events/export/session-report.ts`:
   - Export `sessionReportQueue = new Queue('pdf-session-report', { connection: bullmqConnection })`.
   - Export `exportSessionReportController` that reads `req.query.sessionId` and `req.query.format` (default `pdf`), validates sessionId, fetches the Session with populated participants + speaker, builds a cache key `createKey('events', 'session-report', format, req.user.id, sessionId)`, checks for existing job, enqueues if not, returns processing/completed status.
   - The queue job data shape: `{ sessionId, user: req.user.id, format }`.

2. Create `src/events/export/session-excel.service.ts`:
   - Export `createSessionExcel(data, filePath)` using ExcelJS, mirroring `src/attendance/export/excel.service.ts`.
   - Columns: Participant Name, Phone, Status (present/absent), Session Date, Session Title.
   - Summary rows: session title, date range, total present, total absent.

3. Mount in `src/events/events.routes.ts`:
   ```
   eventRouter.get('/export/report', authorize('read', 'event'), exportSessionReportController);
   ```

### acceptance_criteria

- `grep "sessionReportQueue" src/events/export/session-report.ts` finds the Queue declaration.
- `grep "export/session-report" src/events/events.routes.ts` finds the import.
- `pnpm typecheck` exits 0.

## Task 2: Create session report worker

### read_first

- `src/worker/attendance-report.ts` — the worker to mirror
- `src/worker/index.ts` — where workers are registered
- `src/worker/attendance/template/attendance-pdf.ts` — PDF HTML template pattern
- `src/libs/utils/notification.ts` — notification with action pattern
- `src/libs/utils/browser.ts` — getBrowser
- `src/events/export/session-report.ts` — the queue name and job data shape (from Task 1)

### action

1. Create `src/worker/session-report.ts`:
   - Import and reference `pdf-session-report` queue.
   - Export `sessionReportWorker = new Worker('pdf-session-report', handler, { connection: bullmqConnection })`.
   - Handler: fetch Session by `job.data.sessionId` (populate participants, speaker, program, workshop, images, bills), generate HTML body for PDF via a template function, save PDF to `public/temp/${job.id}.pdf`, for xlsx call `createSessionExcel`, send notification to `job.data.user` with download action pointing to `/api/attendance/download/${job.id}.{pdf|xlsx}` (reuse existing download route — ponytail: it serves any file from `public/temp/`).
   - Reuse the same A4 page format, header/footer, and brand styling from `attendance-pdf.ts`.

2. Register in `src/worker/index.ts`: import `sessionReportWorker` to ensure it starts when the worker process boots.

- `grep "session-report" src/worker/index.ts` finds the import.
- `pnpm typecheck` exits 0.
- `pnpm lint` exits 0.
