# Plan 04-01: Enable Soft-Delete Restore in Events Module

## Objective

Remove the `underDevelopment` middleware from all four restore routes in `events.routes.ts` so that soft-deleted workshops, sessions, programs, and participants can be restored in production.

## must_haves

- [ ] All four `PATCH .../restore/:id` routes in `events.routes.ts` no longer have `underDevelopment` in their middleware chain.
- [ ] Restore routes still have `authorize('update', 'event')`.
- [ ] Existing test `tests/events/events.test.ts` passes (`pnpm vitest run tests/events`).
- [ ] No other code is modified (scope-limited change).

## Task 1: Remove `underDevelopment` from restore routes

### read_first

- `src/events/events.routes.ts`
- `src/libs/middleware/development.ts`
- `tests/events/events.test.ts`

### action

In `src/events/events.routes.ts`, remove the `underDevelopment` import and strip it from the four `eventRouter.patch(...)` restore routes:

1. `eventRouter.patch('/workshops/restore/:id', ...)` — remove `underDevelopment` from the handler chain.
2. `eventRouter.patch('/sessions/restore/:id', ...)` — same.
3. `eventRouter.patch('/participants/restore/:id', ...)` — same.
4. `eventRouter.patch('/programs/restore/:id', ...)` — same.

After removing all four usages, remove the `import { underDevelopment } from '../libs/middleware/development.js';` line entirely (dead import).

### read_first (for verification)

- `src/events/events.routes.ts` (after edit — confirm `underDevelopment` absent from file)

### acceptance_criteria

- `grep -c "underDevelopment" src/events/events.routes.ts` exits with code 0 and outputs `0`.
- `grep "underDevelopment" src/events/events.routes.ts` exits with code 1 (not found).
- `pnpm typecheck` exits 0.
- `pnpm vitest run tests/events` exits 0 (restore tests pass without 503 in production env).
